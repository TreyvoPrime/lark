# Lark 4.8.6

- Adds detachable Scratch windows with docking, recovery, and always-on-top controls where supported.
- Adds named, colored bookmarks with groups, navigation, location review, and a resizable tray.
- Keeps console and Scratch programs running without the former five-minute execution limit.
- Reduces browser autofill and input assistance in IDE text fields.
- Preserves the file-watcher, native tooling, and other improvements from Lark 4.8.5.
