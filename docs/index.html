Lark

A Java IDE that fits in a zip.

Unzip one folder, open Start Lark, and write code. Java is already inside — no admin password, no installer, school-laptop friendly.

Download for your computer All releases

Pick your computer

Each zip includes Lark and a portable JDK. Keep the whole folder together after unzipping.

Windows

Unzip, then double-click Start Lark.bat. Leave the window open — your browser opens to Lark.

Mac

Unzip, then double-click Start Lark.command. If macOS warns you, right-click → Open.

Linux

Unzip, open that folder in a terminal, and run ./start-lark.sh.

Download for Linux
  1. Download the zip for your computer from GitHub Releases.
  2. Unzip into a simple folder name (avoid parentheses), e.g. Documents\Lark.
  3. Open the launcher. Keep that window open while you work.
  4. Optional: connect GitHub with a classic token that has the repo scope.
