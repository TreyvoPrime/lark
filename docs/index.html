Download Lark

A lightweight Java IDE for school and practice. Unzip one folder, open the launcher, and code. Java is already inside the zip — no admin password and no extra download.

Windows

Unzip the whole folder, then double-click Start Lark.bat. Leave the window open — the browser opens to Lark.

Mac

Unzip, then double-click Start Lark.command. If macOS warns you, right-click → Open.

Download for Mac

Linux

Unzip, open that folder in a terminal, and run ./start-lark.sh.

Download for Linux
  1. Click the button for your computer. The zip always comes from the latest GitHub release.
  2. Unzip into Downloads or Documents. You should see Start Lark, lark.jar, and a jdk folder together.
  3. Open the launcher. Leave that window open — your browser opens to Lark.
  4. In Lark, use GitHub → create a classic token with the repo scope → paste and connect.
