Two ways to run Lark

Same IDE. Different packaging. Pick Desktop if you want Start Menu shortcuts and guided setup. Pick Executable if you need a folder you can unzip and run — no installer, no batch files.

Recommended

Lark Desktop

Windows Setup wizard with Start Menu and desktop shortcuts. Installs under your user folder. Runtime stays buried beside Lark Desktop.exe. Prompts for updates on launch.

  • Windows · Setup.exe
  • ~45 MB download
  • ~200 MB with JDK
Download LarkDesktopSetup.exe

Mac / Linux: mac.zip · linux.zip

No installer

Lark Executable

Extract All, then double-click Lark.exe. Built for labs and USB drives that block scripts. Same buried app\ and jdk\ layout — you mainly see the executable.

  • Windows · zip
  • ~72 MB
  • No .bat required
  • Own update channel
Download lark-executable-windows.zip

Do not run from inside a zip preview or Temp folder.

1. Install or extract

Run the Setup wizard, or Extract All the Executable zip to a real folder.

2. Open Lark

Start Menu → Lark Desktop, or double-click Lark.exe.

3. Write Java

Open a project, use live compile feedback, Run with Ctrl+Enter, search with Ctrl+Shift+F.

Other Lark versions

Desktop and Executable are the main tracks. Mobile ships as a separate touch-first edition. Anything else stays clearly marked.

Lark Mobile

Touch-first UI with bottom tabs. Pair a phone over Wi‑Fi to a host PC that still does the compile and run. Separate zips for Windows, Mac, and Linux.

Mac / Linux Desktop payload

Zip payloads with start-lark-desktop.sh and the same buried app/ + jdk/ layout. Windows Setup remains the primary Desktop path.
