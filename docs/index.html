Lark

One folder. Any computer.

Download Lark, unzip it, and open the launcher for this computer. It stays in your user folder. It does not ask for an administrator username or password.

Windows, Mac, and Linux use the same folder

Windows

Unzip, then double-click Start Lark.bat.

Download for Windows

Mac

Unzip, then double-click Start Lark.command. If macOS warns you, right-click and choose Open.

Download for Mac

Linux

Unzip, open that folder in a terminal, and run ./start-lark.sh.

Download for Linux

Official downloads also live on the GitHub Releases page for this project.

  1. Save the zip into Downloads or Documents.
  2. Unzip it. You should see lark.jar next to the launcher.
  3. Open the launcher. If Java is missing, Lark downloads a private copy into your user folder the first time.
  4. In Lark, open GitHub, create a classic token with the repo scope, paste it, and connect.
