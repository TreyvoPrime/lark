Setup

Get started

Short paths for PC and Android. Same IDE either way.

On a PC

1. Download

Get Executable (Windows) or Desktop (Setup / Mac / Linux) from Downloads above.

2. Open Lark

Extract the zip → double-click Lark.exe, or finish Desktop Setup and launch from the Start Menu.

3. Write Java

Open a project, use live compile feedback, Run with Ctrl+Enter, search with Ctrl+Shift+F.

On Android

1. Install the APK

Download Lark Mobile APK, allow install from that source, then open the app.

2. Start on this phone

Tap Start (or wait for auto-start). First launch unpacks the bundled Android JRE once.

3. Code and Run

Create a project and run Java on the device. If Start fails, pair a PC host over Wi‑Fi instead.
