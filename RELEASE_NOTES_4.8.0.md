# Lark 4.8 — Distinctly Lark

Lark 4.8 introduces a refined desktop visual system while preserving the existing editor, project workflow, themes, shortcuts, terminal, debugger, and Lark Share protocol.

- Reworked desktop chrome with a clearer Lark 4.8 identity and high-emphasis Run control.
- Unified premium surface, border, radius, focus, elevation, and motion tokens across existing themes.
- Refined Explorer, tabs, terminal/output, status bar, dialogs, project cards, menus, settings, and minimap presentation.
- Added responsive toolbar compaction and system reduced-motion support.

Verification: compile and automated checks should be run on each release platform before packaging.
