Lark Enterprise
===============

The installed Lark edition with a real Windows Setup wizard, Start Menu
shortcut, app icon, and its own update channel.

This is NOT Lark Desktop. Desktop remains the default product. You can
install both side by side (~200 MB each with the bundled JDK).

Windows
-------
1. Download LarkEnterpriseSetup.exe
2. Run the installer wizard (no admin password — installs for your user)
3. Open "Lark Enterprise" from the Start Menu or Desktop shortcut

Install location (Windows):
  %LOCALAPPDATA%\Programs\Lark Enterprise

Uninstall: Settings → Apps → Lark Enterprise, or the Start Menu uninstall entry.

Updates
-------
Lark Enterprise checks the same public feed as other editions but downloads
the enterprise update package (jar + launcher only — JDK stays on disk).
