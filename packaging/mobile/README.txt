Lark Mobile
===========

A completely separate touch-first edition of Lark — not the desktop IDE
squeezed onto a small screen.

What you get
------------
• Bottom-tab Mobile UI (Projects, Files, Editor, Run, More)
• Large tap targets, one panel at a time
• Phone pairing: run Mobile on a PC/tablet, open the printed URL on your phone
  (same Wi‑Fi). Compile and run stay on the host machine.
• Same projects folder as Lark when run on the same user account
• In-app updates on the mobile channel

Start
-----
Windows:  double-click  Start Lark Mobile.bat
Mac:      double-click  Start Lark Mobile.command
Linux:    ./start-lark-mobile.sh

Keep the console window open. It prints a Phone URL with a pair code.

Do not run from inside a zip preview / Temp folder.
Keep lark.jar, the Start Lark Mobile launcher, and the jdk\ folder together.
