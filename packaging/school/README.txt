Lark School (Windows) — no .bat file required
==============================================

For school PCs that block batch files (.bat).

How to install
--------------
1. Download lark-school-windows.zip
2. Right-click the zip → Extract All…
   Suggested folder:  C:\Users\YOURNAME\Lark
3. Open the extracted folder
4. Double-click  Lark.exe

You must see these together in one folder:
  • Lark.exe
  • lark.jar
  • jdk\   (a folder)

Do NOT open files from inside the zip preview / Temp folder.

What this is
------------
Same Lark Java IDE as the normal Windows zip — compile, run, debug —
but the starter is a real Windows program (Lark.exe) instead of
Start Lark.bat.

Updates
-------
Use Aa → Check for updates inside Lark, then close and double-click
Lark.exe again if it asks you to restart.

If something fails
------------------
Open lark-school-boot.log next to Lark.exe, or re-download and
Extract All into a new folder.
