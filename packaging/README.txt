Lark

Unzip this folder anywhere you are allowed to save files, such as Downloads or Documents.
Lark does not install itself for every user, and it does not ask for an administrator password.

Windows: double-click "Start Lark.bat"
Mac: double-click "Start Lark.command"
  If macOS says it cannot be opened, right-click it, choose Open, then Open again.
Linux: open this folder in a terminal and run ./start-lark.sh

The same folder works on all three. Use the launcher that matches the computer.

If Java 17 or newer is already installed, Lark uses it.
If it is not, the launcher downloads a private copy into your user folder, under .lark/jdk.
That download needs an internet connection the first time. It does not need an admin password.

Lark then opens its own window. Your projects are saved in your user folder, under .lark/projects.
