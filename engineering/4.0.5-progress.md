# Lark 4.0.5 implementation and verification report

The Java 17 backend serves plain JavaScript and CodeMirror 5. Runner uses javac/java; Debugger uses jdb. Share is a separate authenticated, pinned TLS 1.3 protocol with mandatory host approval, stable character identities, local operation history and DNS-SD discovery. Mobile uses the existing backend and web-mobile. docs/ is the website; packaging/ produces installers/archives. Android client source now exists under android/.

## Security scope
Mobile LAN now requires configured HTTPS and a trusted certificate. Pairing is an owner credential, not anonymous access. Same-origin cookie bootstrap loads phone assets correctly. Remote clients cannot use host GitHub, terminal, updater or recovery control APIs. Java is explicitly launched by the user; no automatic collaborator execution was added. Heap/processor/output/time controls are resource limits, not a security sandbox. A dedicated account/container/VM is necessary for untrusted code. Mobile Share integration cannot be claimed simply by exposing host Share control APIs; those remain local-only.

## Build/test environment limits
Chrome was downloaded successfully, but cannot start because the environment denies the socket required by its process singleton. DOM tests run the actual CodeMirror implementation and event handlers; they do not replace physical browser testing. GitHub's first stability job completed with no executed steps and no retrievable logs, so it is not a passing CI run. Android SDK, Gradle and package tooling were provisioned locally; the Android build/lint/signature checks are actual local results. No Android emulator, iPhone/iPad or Windows installation was exercised.

This report deliberately distinguishes implemented source, successful local tests, and unfinished specification items. The original ten-phase specification is not fully satisfied while these gaps remain.

## Follow-up source changes

Share editor startup is now deduplicated and cancellable. Leaving during the file-list request or paginated history loading cannot reactivate the old editor. Documents become visible to polling only after initial history is complete. Stalled pagination fails cleanly, failed startup releases the session, and leaving detaches document listeners and recovery timers. A new session can poll independently of a still-pending old request. The dependency-free lifecycle regression covers cancellation, restart, partial history, duplicate startup, cleanup and failure handling.

Desktop and mobile typing now exclude comments/literals when inferring variable types, discard declarations from completed brace blocks, respect local shadowing, and recognize qualified common types and array members. This remains lightweight lexical assistance, not full Java semantic or method-scope resolution.

The earlier candidate kit and artifact hashes above describe the previous build. These follow-up source changes require a fresh packaged release before they are present in that download. Mobile Share joining, OS execution isolation and physical platform validation remain outstanding.
