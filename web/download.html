Save Lark

Click the button. Your browser should put lark.zip in your downloads folder. That earlier link pointed at a file on the computer running Lark, so there was nothing for your browser to save.

  1. Unzip lark.zip. You should see lark.jar and Start Lark.bat in the same folder.
  2. On Windows, double-click Start Lark.bat. You do not need to cd first. On Mac or Linux, open that folder and run ./start-lark.sh.
  3. Lark needs a JDK 17 or newer. If the window says Java is missing, install one from adoptium.net and start Lark again.

If the button does nothing, right-click this link and choose “Save link as…”, then name the file lark.zip.
