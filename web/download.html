Lark

One folder. Any computer.

Download Lark, unzip it, and open the launcher for this computer. It stays in your user folder. It does not install for every account, and it does not ask for an administrator username or password.

Windows, Mac, and Linux use the same folder

Windows

Unzip, then double-click Start Lark.bat.

Download for Windows

Mac

Unzip, then double-click Start Lark.command. If macOS warns you, right-click it and choose Open.

Download for Mac

Linux

Unzip, open that folder in a terminal, and run ./start-lark.sh.

Download for Linux

  1. Save the zip into Downloads or Documents. You do not need permission to write anywhere else.
  2. Unzip it. You should see lark.jar next to the launcher.
  3. Open the launcher. If Java 17 or newer is already on the computer, Lark uses it. If not, it downloads a private copy into your user folder the first time. That download needs the internet. It still does not need an admin password.
