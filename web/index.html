Practice tips

  • Use Java → Generate getters/setters while learning encapsulation.
  • Type /** above a method for a Javadoc stub.
  • Press Ctrl+Space for keywords and project classes.
  • When a program asks Y/N, answer in the Output reply box — not while naming a class.
